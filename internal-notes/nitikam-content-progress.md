## ไฟล์ต้นฉบับอยู่ที่ไหน
PDF ต้นฉบับทั้ง 38 ไฟล์ (ที่พี่ส่งผ่านแชท): เดิมอยู่ที่
`/root/.claude/uploads/<session-id>/` — path นี้ผูกกับ session เดิม อาจไม่มีใน
session ใหม่ ถ้าเปิดมาแล้วหาไฟล์พวกนี้ไม่เจอ ให้ขอพี่ส่งไฟล์ที่เหลือ (สัมมนา +
handout + แบบฝึกหัด) มาใหม่อีกครั้ง

ข้อความที่ดึงด้วย `pdftotext -layout` ไว้แล้วสำหรับทุกไฟล์ (ฟรี ไม่เสีย token)
เคยอยู่ที่ `scratchpad/pdftext/*.txt` — ก็ผูกกับ session เดิมเช่นกัน ถ้าหายไป
ให้รัน `apt-get install -y poppler-utils` (ถ้ายังไม่มี) แล้ว
`pdftotext -layout <ไฟล์.pdf> <ไฟล์.txt>` ใหม่ทีละไฟล์ (เร็วมาก ไม่กี่วินาที/ไฟล์)

## Workflow ที่ใช้ได้ผลดีตลอด (แนะนำให้ทำต่อแบบเดิม)
1. `pdftotext -layout` ดึงข้อความจริงจาก PDF (ฟรี, แม่นยำ 100%, ห้ามให้โมเดลอ่าน
   ภาพสไลด์ตรงๆ เพราะเคยลองแล้วมั่ว/เดาคำศัพท์กฎหมายผิดบ่อย)
2. ส่ง subagent รุ่น **Haiku** (ประหยัด) ไปจัดรูปแบบข้อความที่ดึงมาแล้วให้เป็น
   markdown ตามสไตล์เว็บ (ดูตัวอย่าง prompt ที่เคยใช้ได้ผลดีใน git log ของ commit
   ก่อนหน้าในไฟล์นี้ หรือดู pattern จาก `classroom-law.js` ที่ทำไปแล้ว)
3. Sonnet (ตัวหลัก) อ่านผลลัพธ์ ตรวจทาน แล้วเขียนเป็น `LESSON_CONTENT.nitikam`
   entry ใหม่ใน `classroom-law.js` (ย่อให้กระชับขึ้นบ้างแต่รักษาเลขมาตรา/
   คำพิพากษา/ชื่อนักวิชาการให้ครบถ้วนแม่นยำ)
4. คัดข้อสอบท้ายไฟล์มาใส่ `EXAM_QUESTIONS.nitikam` (เขียนแนวคำตอบเองจากหลัก
   กฎหมายที่เพิ่งสรุปไป) — ข้ามข้อที่ซ้ำกับที่เคยใส่ไปแล้ว
5. `node --check classroom-law.js`, bump `sw.js` CACHE เวอร์ชันถัดไป, commit,
   push, ตรวจสอบ GitHub Actions deploy ด้วย Monitor tool จนสำเร็จ
6. รายงานพี่เป็นภาษาไทยสรุปสั้นๆ ว่าเพิ่มอะไรไปบ้าง เหลืออะไรบ้าง
