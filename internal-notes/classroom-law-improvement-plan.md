# แผนปรับปรุงหน้า "เรียนกฎหมาย" (classroom-law.html/.js) — สรุปจาก brainstorm

> ไฟล์นี้เป็นบันทึกภายในสำหรับผู้พัฒนา (พี่ + Claude) เท่านั้น ไม่ได้ถูกอ้างอิงจาก
> HTML/JS ของเว็บจริง ไม่กระทบผู้เข้าชมเว็บ — เก็บไว้ให้ session ถัดไปอ่านต่อได้
> แม้ scratchpad ของ session เดิมจะหายไปแล้ว (เพราะ container เป็น ephemeral)

สถานะ ณ ตอนเขียน (หลังทำหัวข้อ 1-12 ของวิชานิติกรรมสัญญาเสร็จ กำลังเตรียม 14-15):
เนื้อหาบทเรียนเริ่มเยอะและยาวขึ้นเรื่อยๆ พี่เลยขอให้ช่วย brainstorm วิธีนำเสนอ/
เครื่องมือเพิ่มเติม สรุปไอเดียทั้งหมดที่คุยกันไว้ด้านล่าง (ยังไม่ได้เริ่มทำจริงสักข้อ
รอพี่ยืนยันตอนเปิด session ใหม่)

## 1. UX/การนำทาง (เร่งด่วนสุด เพราะกระทบการอ่านเนื้อหาที่มีอยู่แล้วโดยตรง) — ✅ ทำเสร็จแล้ว
1. ✅ **สารบัญหัวข้อแบบ chip** บนสุดของการ์ดบทเรียน — กดแล้วเลื่อน+เปิดหัวข้อนั้นทันที
   (implement: `.lchips`/`.lchip` ใน classroom-law.js `renderLessonContent()`)
2. ✅ **จัดกลุ่มเป็น "ภาค"** ตามเนื้อหาจริง (ภาคนิติกรรม = หัวข้อ 1-8, ภาคสัญญา = หัวข้อ
   9-15) ผ่าน metadata `LESSON_CONTENT.nitikam.groups` (ใช้ `count` สะสมจาก `parts`
   — ถ้าเพิ่มหัวข้อใหม่ภายหลังต้องอัปเดต `count` ให้ตรงด้วย) — วิชาอื่นที่ไม่มี
   `groups` จะ fallback เป็นรายการเรียบ (flat) อัตโนมัติ
3. ✅ **ติ๊กว่าอ่านแล้ว** ต่อหัวข้อ (เก็บใน `localStorage` คีย์ `tanot:barprep:lessonread`
   โดยใช้ชื่อหัวข้อ/title เป็นคีย์ย่อย ไม่ใช่ index — กันปัญหาถ้าลำดับหัวข้อเปลี่ยนภายหลัง)
   + progress bar % ของวิชา (`.lprog`/`.lprog-fill`)
4. ✅ **ข้อสอบจัดกลุ่มตามหัวข้อ** — เพิ่มฟิลด์ `topic: N` ให้ข้อสอบ nitikam ทั้ง 47 ข้อ
   (map เทียบจากเนื้อหา/เลขมาตราที่อ้างในแต่ละข้อ ไล่ตรวจเทียบด้วยมือ ไม่ใช่ auto 100%
   — ถ้าพบข้อไหนจัดหมวดผิดพลาดภายหลัง แก้ที่ฟิลด์ `topic` ของข้อนั้นได้เลยใน
   `EXAM_QUESTIONS.nitikam`) จัดกลุ่มแสดงผลผ่าน `NITIKAM_TOPIC_LABEL` +
   กล่องค้นหา/กรองด้วยคำสำคัญหรือเลขมาตรา (`#exqSearch`) และ dropdown กรองตามหัวข้อ
   (`#exqTopicFilter`) ใน `renderExamQuestions()` — วิชาอื่นที่ไม่มี `topic` fallback
   เป็นรายการเรียบพร้อมช่องค้นหาเฉยๆ (ไม่มี dropdown หัวข้อ)

ทดสอบแล้วด้วย Playwright (headless Chromium) ผ่าน local http server — chip
คลิกแล้วเปิด+เลื่อนถูกหัวข้อ, ติ๊กอ่านแล้วอัปเดต progress bar ถูกต้องและไม่ปิด
หัวข้อที่เปิดค้างอยู่, ค้นหา/กรองข้อสอบทำงานถูกต้อง (ทดสอบทั้งค้นคำ, ค้นเลขมาตรา,
กรองตามหัวข้อ, และ empty-state เมื่อค้นไม่เจอ) ไม่มี JS error ขึ้น deploy แล้ว
(sw.js v143)

## 2. เครื่องมือการเรียน (เพิ่ม)
5. **โหมดทำข้อสอบจริง (Mock Exam)** — สุ่มโจทย์จากธนาคารข้อสอบที่มีอยู่ จับเวลาเอง
   แล้วเปิดเฉลยเทียบ (ตอนนี้ข้อสอบเป็นแค่รายการอ่านเฉยๆ)
6. **Auto-flashcard จากเนื้อหาบทเรียน** — ดึงคำที่ทำ `==เน้น==` ไว้ในเนื้อหามาสร้าง
   flashcard อัตโนมัติ ไม่ต้องพิมพ์เอง
7. **อัปเกรด SRS เป็น FSRS** (Free Spaced Repetition Scheduler) แทนขั้นบันไดที่คิดเอง
8. **ดัชนีค้นมาตรา** — พิมพ์เลขมาตรา แล้วเจอทุกจุดที่เคยพูดถึงมาตรานั้น ข้ามทุกวิชา/
   ทุกหัวข้อ (มีประโยชน์มากตอนอ่านทวนใกล้สอบ)
9. **คลังฎีการวม** — ค้นด้วยเลขคดีหรือคำสำคัญ รวมฎีกาที่อ้างไว้กระจายในหลายหัวข้อ
10. **โหมดฝึกจำเลขมาตรา (drill สั้นๆ)** — โจทย์สถานการณ์สั้นมาก ให้ทายมาตรา ตอบเร็ว
    เช็กเร็ว ต่างจาก mock exam ตรงที่เป็นชุดสั้นๆ ทำได้หลายรอบต่อวัน
11. **ไฮไลต์/จดโน้ตส่วนตัวลงในเนื้อหาบทเรียนโดยตรง** — ลดขั้นตอนเทียบกับสมุดโน้ต
    แยกการ์ดที่มีอยู่ตอนนี้
12. **Export เป็น PDF ต่อวิชา** — สำหรับพิมพ์อ่าน/ขีดเขียนบนกระดาษ

## 3. เครื่องมือการเรียน (พิจารณาตัด/ซ่อน — ยังไม่ฟันธง รอพี่ยืนยันว่าใช้บ่อยแค่ไหน)
- 📷 นำเข้ารูป→OCR→บันทึกโน้ต (ซับซ้อน อาจไม่ค่อยได้ใช้ — ถ้าไม่บ่อยควรย้ายไปเมนูรอง)
- 🧭 เช็กเส้นทาง 3 สายอาชีพ (ถ้าตัดสินใจสายอาชีพไปแล้วอาจไม่จำเป็นต้องเด่นอีก)

## 4. เสียงอ่าน (ต่อยอดจากระบบ TTS ที่มีอยู่แล้วในเว็บ — text-to-speech.js/tts-worker.js)
13. ปุ่ม **"🔊 ฟังเนื้อหานี้"** ในแต่ละหัวข้อบทเรียน (และข้อสอบตัวอย่างถ้าต้องการ)
14. **โหมดเล่นต่อเนื่องทั้งวิชา (playlist)** — จบหัวข้อหนึ่งเล่นหัวข้อถัดไปอัตโนมัติ
    เหมาะกับฟังตอนออกกำลัง/เดินทาง แบบพอดแคสต์
15. แปลง markdown เป็นข้อความอ่านลื่นก่อนส่งเข้า TTS (ตัด `**`, `##`, สัญลักษณ์พิเศษ)
16. ปุ่มเล่น/หยุดชั่วคราว/ข้ามหัวข้อถัดไป-ก่อนหน้า
17. **ข้อควรระวัง**: ใช้เสียง "หญิง/ชาย ทั่วไป" (เวอร์ชันที่แก้บั๊กแล้ว) เป็นค่าเริ่มต้น
    ห้ามใช้เสียง "หญิง (โทนพอดแคสต์)" เป็นค่าเริ่มต้นของฟีเจอร์นี้ จนกว่าจะไปตรวจสอบ
    บั๊ก "หน้าเว็บรีเฟรชเอง" ที่สงสัยว่าเกี่ยวข้องกับเสียงนี้ให้เสร็จก่อน (ปัญหานี้
    ถูกเลื่อนไว้ทำหลังสุดตามที่พี่ขอไว้ตั้งแต่ต้น session)

## สถานะการตัดสินใจ

— ทำข้อ 1-4 (UX) เสร็จแล้วตามลำดับความสำคัญที่วางไว้ (ดูเครื่องหมาย ✅ ด้านบน)

**ต่อไป**: ข้อ 5-12 (เครื่องมือการเรียนเพิ่มเติม — mock exam, auto-flashcard, FSRS,
ดัชนีค้นมาตรา, คลังฎีการวม, drill มาตรา, ไฮไลต์/โน้ตในเนื้อหา, export PDF) และข้อ

อยากให้ทำข้อไหนต่อ หรือเรียงตามลำดับในไฟล์นี้ไปเลย (5→17)
