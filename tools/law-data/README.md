# tools/law-data — สร้างชุดตัวบทของห้องเรียนกฎหมาย (ROADMAP แถว 9c)

สคริปต์ที่เจ้าของรันในเครื่อง ไม่อยู่ใน CI · ไม่เรียกเครือข่าย/AI · อ่านไฟล์ต้นฉบับอย่างเดียว
ผลลัพธ์: `law-packs/<code>-<sha256 8 ตัว>.json.gz` + `law-packs/index.json` (แบบ `docs/law-classroom-design.md` 5.4/5.5)

```
{v:1, code, name, src, asOf:'YYYY-MM-DD', s:[{n:'150', b:'หมวด ๑ …', t:'ข้อความเต็ม', f?:['เชิงอรรถ']}], x?:[{h, t}]}
```

- `code` ต้องอยู่ใน `LawCalc.CODES` (`law-calc.js`) — ไม่มีตารางรหัสซ้ำที่นี่ · `name` มาจากตารางนั้น
- `n` = เลขมาตราแบบเดียวกับ `LawCalc.refKey` (`150`, `150/1`, `7ทวิ`) · `b` = หัวที่มาตรานั้นอยู่ (ภาค › ลักษณะ › หมวด … / บทเฉพาะกาล)
- `f` = เชิงอรรถ (ประวัติการแก้ไขจากราชกิจจานุเบกษา) · `x` = ส่วนท้าย เช่น อัตราค่าธรรมเนียมท้าย พ.ร.บ. (เป็นตัวบท ห้ามทิ้ง)
- `asOf` = วันที่ราชกิจจานุเบกษาล่าสุดที่เชิงอรรถอ้าง (= ฉบับแก้ไขล่าสุดที่ข้อความนี้รวมไว้) หรือ `--as-of`
- **ห้ามย่อ ห้ามตัด** (แบบ 5.0): ทุกมาตราครบทุกตัวอักษร · สคริปต์แก้ได้เฉพาะรหัสตัวอักษรที่ฟอนต์ PDF เพี้ยน (ํ+า → ำ, U+FFFD) · ถ้อยคำที่ PDF ต่างจากฉบับกฤษฎีกาแก้ผ่าน `corrections.json` เท่านั้น (ต้องพบข้อความเดิมครั้งเดียวพอดี + เหตุผล)

## รัน

```
cd tests && npm ci          # ใช้ pdfjs-dist ที่ล็อกไว้ใน tests/package.json
node tools/law-data/build.mjs --code lawyer --pdf "E:/law/พระราชบัญญัติทนายความ พ.ศ.๒๕๒๘.pdf" \
  --ref thailaw.jsonl --ref-title "พระราชบัญญัติทนายความ พ.ศ. 2528" --appendix "อัตราค่าธรรมเนียม"
node tools/law-data/build.mjs --code ethics --pdf "E:/law/ข้อบังคับสภาทนายความว่าด้วยมรรยาททนายความ พ.ศ.๒๕๒๙.pdf" \
  --ref thailaw.jsonl --ref-title "ข้อบังคับสภาทนายความ ว่าด้วยมรรยาททนายความ พ.ศ.2529"
```

ตัวเลือก: `--as-of YYYY-MM-DD` · `--appendix "<หัวส่วนท้าย>"` (ซ้ำได้) · `--src "<ที่มา>"` · `--out <โฟลเดอร์>` · `--dry` (ตรวจอย่างเดียวไม่เขียน)
เขียนไฟล์ใหม่แล้วลบไฟล์เก่าของรหัสเดียวกัน + อัปเดต `index.json` → bump `CACHE` ใน `sw.js` → แก้ตัวเลขที่ตรึงไว้ใน `tests/law.spec.js` (จำนวนมาตรา/ตัวอักษร) → `cd tests && npx playwright test law.spec.js`

## ทางเดิน (`lib.js` — ตรรกะล้วน, `build.mjs` — I/O)

1. pdf.js อ่านข้อความรายชิ้นพร้อมตำแหน่ง/ขนาด → บรรทัด: ตัดลายน้ำ "สำนักงานคณะกรรมการกฤษฎีกา" และเลขหน้า · แยกเชิงอรรถตามขนาดตัวอักษร · เลขเชิงอรรถยกสูงผูกกับตำแหน่งในข้อความ
2. ย่อหน้า = บรรทัดที่เยื้องเข้า · บรรทัดกึ่งกลาง = หัวภาค/หมวด (บรรทัดกึ่งกลางถัดไป = ชื่อหมวด)
3. ต่อบรรทัด: ไทยชนไทยใส่รอย `WRAP` ไว้ → `resolveWraps` ดูฉบับกฤษฎีกาว่าตรงนั้นมีช่องว่างหรือไม่ (ไม่มีฉบับอ้างอิง = ต่อติด)
4. แยกมาตรา/ข้อ เลือกช่วงเลขที่เรียงขึ้นยาวที่สุด (ตัดมาตราของ พ.ร.บ.ให้ใช้ประมวล และบทเฉพาะกาลของฉบับแก้ไข)
5. `garbleReport` ปฏิเสธ PDF ที่ฟอนต์เพี้ยนจนวรรณยุกต์/สระกลายเป็นอักษรละติน (ไม่เดาซ่อม) · `checkPack` ตรวจรูปแบบเลข/ลำดับ/ซ้ำ/ลายน้ำ/อักขระควบคุม
6. `--ref`: เทียบตัวอักษรทุกมาตรากับ thailaw (ไม่นับช่องว่าง/เครื่องหมายคำพูด/เลขเชิงอรรถ) แล้วพิมพ์จุดที่ต่าง — ต้องได้ "ต่าง 0" ก่อน commit

### PDF "ฉบับ Update ล่าสุด" ของกฤษฎีกา (`E:\law\กฤษฎีกา\`, ฟอนต์ Bai Jamjuree)

- **glyph ไม่มีรหัส**: วรรณยุกต์ยกสูง/เลื่อนซ้าย (`uni0E48.small`, `uni0E49.narrow` …), ญ ฐ ตัดหาง และ ํ+วรรณยุกต์ของ "ำ" ไม่มี ToUnicode → pdf.js คืน U+0000 ("เมื อ") · `build.mjs` อ่าน CID จาก operator list ของหน้าเดียวกันตามลำดับ แล้ว `fillUnmappedGlyphs` แทนด้วย `BAI_JAMJUREE_UNMAPPED` — ตารางถอดจากชื่อ glyph ในตาราง `post` ของ BaiJamjuree-Regular/SemiBold.ttf (google/fonts, OFL) เพราะ CID ใน PDF = GID ของฟอนต์ต้นฉบับ (ตรวจกับ CID ที่มี ToUnicode แล้ว) · จำนวน/ลำดับ/ฟอนต์ไม่ตรง = หยุด ไม่สร้างชุด · ยืนยันผลแล้ว: พระธรรมนูญศาลยุติธรรมเทียบ thailaw "ต่าง 0" ทุกมาตรา
- **บรรทัดที่มีแต่วรรณยุกต์** (เศษ glyph ท้ายหน้า ไม่มีพยัญชนะ) ทิ้ง · เลขหน้า "| 16"
- **เชิงอรรถ** เป็น "[12]" ขนาด ~0.75 ของตัวเนื้อ และอยู่ท้ายเล่ม (หลังบรรทัดผู้รับสนองฯ/หมายเหตุ บรรทัดที่ขึ้นต้นด้วย [n])
- **กล่องความเห็นกฤษฎีกา** ("เรื่องเสร็จที่ …" → "บันทึกสำนักงานคณะกรรมการกฤษฎีกา เรื่อง …" → "สำหรับรายละเอียดของความเห็นฯ โปรดดูที่ไฟล์ PDF") แทรกระหว่างบรรทัดตัวบท — ไม่ใช่ตัวบท `stripOpinionBoxes` ตัดทีละบรรทัดก่อนรวมย่อหน้า · กล่องไม่ครบรูปแบบ = หยุด
- เลขมาตรา `๑๗๒ ทวิ/๑` (ป.วิ.อ.) → `172ทวิ/1` (รองรับใน `LawCalc` ด้วย)
