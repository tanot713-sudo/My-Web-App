# tools/colab — หนังสือเสียงคุณภาพสูง (F5-TTS-THAI บน Google Colab)

สร้างหนังสือเสียงภาษาไทยทั้งเรื่องจากไฟล์ `.txt` ด้วย F5-TTS-THAI (VIZINTZOR, แพ็กเกจ [`f5-tts-th`](https://pypi.org/project/f5-tts-th/) 1.0.9) → MP3 แยกตามตอน เก็บใน Google Drive · 2 เสียง: หญิง (รุ่น v1) และชาย (รุ่น v2)

โมเดล ~1.3 GB/รุ่นและต้องใช้ GPU จึงรันในเบราว์เซอร์ไม่ได้ — หน้าเว็บ (แปลงเสียง ↔ ข้อความ → การ์ด "หนังสือเสียงคุณภาพสูง (Google Colab)") พาไปเปิดใน Colab

- เปิด: https://colab.research.google.com/github/tanot713-sudo/My-Web-App/blob/main/tools/colab/tanot-audiobook-f5.ipynb
- `tanot_audiobook_f5.py` — สคริปต์ (ต้นฉบับ ทดสอบกับงานจริงแล้ว) · แบ่งตอน/แปลงข้อความด้วย `tts-long.js` + `tts-normalize.js` ของเว็บ (ดึงจาก `main`)
- `tanot-audiobook-f5.ipynb` — สร้างจาก `.py` ด้วย `node tools/colab/build-notebook.js` (**แก้ .py แล้วต้องรันซ้ำ** — `tests/colab.spec.js` ตรวจว่า cell โค้ดตรงกับ .py ทุกตัวอักษร)

## ต้องมีอะไร

- บัญชี Google (Colab + Google Drive ที่มีที่ว่างพอ — MP3 64 kbps ≈ 29 MB/ชั่วโมงเสียง/เสียง)
- GPU **L4** ต้องใช้ Colab Pro (หรือ compute units) · T4 ของ Colab ฟรีน่าจะใช้ได้แต่ช้ากว่า — **ยังไม่ได้วัด**
- เสียงตัวอย่าง 2 ไฟล์: `ref-F-C.wav` (หญิง) และ `ref-M-C.wav` (ชาย) ยาว 6–8 วินาที พูดประโยคนี้ตรงทุกคำ (`REF_TEXT["C"]` ในสคริปต์):
  > ถ้าเราไม่ลองตอนนี้ ก็ไม่มีวันรู้หรอกว่าผลจะออกมาเป็นอย่างไร พรุ่งนี้เช้าค่อยมาคุยกันใหม่นะ

## ใช้งาน

1. หน้าเว็บ: วาง/แนบข้อความ → การ์ด "หนังสือเสียงคุณภาพสูง" → **บันทึกข้อความเป็น .txt** (สร้างไฟล์ในเครื่อง ไม่ส่งข้อความไปไหน) → **เปิดใน Colab**
2. Colab: Runtime → Change runtime type → **L4 GPU** → Save → กด Run
3. อนุญาตให้เข้าถึง Google Drive → อัปโหลดไฟล์ `.txt` (ครั้งแรกเลือก `ref-F-C.wav` + `ref-M-C.wav` ไปพร้อมกัน)
4. ไฟล์อยู่ที่ `My Drive/Tanot หนังสือเสียง/<ชื่อเรื่อง>/<เสียง>/` — ชื่อเรื่อง = ชื่อไฟล์ .txt

**เสียงตัวอย่างเก็บไว้ที่** `My Drive/Tanot หนังสือเสียง/_เสียงตัวอย่าง/` — เรื่องถัดไปอัปโหลดแค่ .txt

**หลุด/ปิดไปกลางทาง**: เปิดลิงก์เดิม เลือก L4 แล้วกด Run ใหม่ — สคริปต์จำเรื่องล่าสุดที่ยังไม่เสร็จและทำต่อเอง (ตอนที่มี MP3 ใน Drive แล้วถูกข้าม เสียได้มากสุดแค่ตอนที่กำลังทำ) · เริ่มเรื่องใหม่ทั้งที่เรื่องเดิมยังไม่เสร็จ = ตั้ง `NEW_BOOK = True` · เปิดแท็บ Colab ค้างไว้ระหว่างทำ (ปิดแท็บ/คอมหลับนาน → Colab ตัดการเชื่อมต่อ) · เสร็จแล้วสคริปต์คืนเครื่อง GPU เอง (`AUTO_DISCONNECT`)

"คำอ่านของฉัน" ของหน้าเว็บไม่ถูกใช้กับ F5 (คำอ่านที่ทดสอบกับ MMS ใช้ตรงๆ ไม่ได้ — `LEXICON` ในสคริปต์ว่างไว้)
