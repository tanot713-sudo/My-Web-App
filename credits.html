หมายเหตุลิขสิทธิ์

  • ชื่อฟอนต์ลิขสิทธิ์ (เช่น Arial, Times New Roman, Calibri, Tahoma, Angsana New, Cordia New, Browallia) ถูกอ้างเป็นชื่อในสไตล์ (CSS) เท่านั้น เว็บไม่ได้แนบหรือเผยแพร่ไฟล์ฟอนต์ — เบราว์เซอร์จะใช้ฟอนต์ที่อยู่ในเครื่องผู้ใช้เอง จึงไม่เข้าข่ายละเมิดลิขสิทธิ์
  • รูปแบบไฟล์ .docx / .xlsx เป็นมาตรฐานเปิด (Office Open XML — ISO/IEC 29500) อ่าน/เขียนได้อย่างเสรี
  • “Word” และ “Excel” เป็นเครื่องหมายการค้าของ Microsoft — ในเว็บนี้ใช้เพื่ออธิบายความเข้ากันได้ของไฟล์ (รองรับ .docx / .xlsx) เท่านั้น ไม่ได้มีความเกี่ยวข้องหรือได้รับการรับรองจาก Microsoft
  • บริการตรวจคำผิด LanguageTool เรียกผ่าน API สาธารณะของผู้ให้บริการ ภายใต้ข้อกำหนดการใช้งานของเขา
